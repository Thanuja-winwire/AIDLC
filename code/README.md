# RAG App

Upload PDF, TXT or Markdown documents and ask questions. Answers are generated by OpenAI from retrieved chunks and cite their sources. Vectors are stored locally in ChromaDB.

## Run locally

```bash
cd code
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                  # then set OPENAI_API_KEY
uvicorn app.main:app_factory --factory --port 8000
```

Open http://localhost:8000. The UI and API share one port, so no proxy or CORS setup is needed.

## Tests

```bash
cd code
pytest
```

Tests use fake embedding and LLM clients, so they need no API key or network.

## API

| Method | Path | Purpose |
|---|---|---|
| GET | /health | Liveness |
| POST | /api/documents | Upload files (multipart field `files`) |
| GET | /api/documents | List documents |
| DELETE | /api/documents/{id} | Delete a document |
| POST | /api/query | `{"question": "..."}` returns the answer and its sources |

Re-uploading a file with the same name replaces the old copy. If no chunk passes the similarity threshold, the app replies that it does not have enough information and does not call the LLM.

## Configuration

See `.env.example` for all settings (models, chunk size and overlap, top-k, minimum similarity, upload limit, Chroma directory).
