# Personas

## Customer — "Casey Shopper"
- **Role**: `customer` (registered user). Guests may browse and search without logging in; cart and checkout require login.
- **Goals**: Find products quickly, buy with minimal friction, track orders.
- **Context**: Uses mobile and desktop; expects clear validation and feedback.
- **Pain points**: Unclear stock, confusing checkout errors, no visibility into order status.
- **Stories**: US-1, US-2, US-3, US-4, US-5, US-6, US-7, US-8, US-9, US-10, US-14

## Admin — "Alex Operator"
- **Role**: `admin`, created via seed script.
- **Goals**: Keep the catalog and stock accurate, fulfil orders, manage users.
- **Context**: Uses the dashboard on desktop, occasionally tablet.
- **Pain points**: Slow bulk review of orders, low-stock surprises, no control over accounts.
- **Stories**: US-11, US-12, US-13, US-14, US-15
